## About

I've spent 4+ years shipping production interfaces in Angular and React. Now I'm asking a different question: what happens when the interface itself can reason? I'm retraining that same eye for structure and detail toward GenAI — model behavior, orchestration, and agentic systems a real user can actually click through.

Currently pursuing an M.Tech in AI & ML alongside hands-on work in LLMs, NLP, and deep learning.
